# This is my Notes app V1 built from scratch

This repository have my beginner frontend project that i built it with HTML, CSS and JS from scratch. This is a normal generic Notes App. This is the version 1 of my notes app. i am going to build another one with better design and colors with extra features.

This project is done to learn web development, especially the frontend using vanilla JS and the CRUD method of applications.

The goal was to build one app for learning how to build CRUD application using vanilla JS and make it functionable and feature heavy.

## This Notes App v1 have :
- Create New Note
- Delete Note
- Editing Note Title
- Editing Note Body
- Localstorage for saving notes locally
- Updating Note after 500ms user types
- keyboard shortcut for creating new note
- Last saved timestamp
- Character and word count
- Search feature by Note title
- Data persistence across different notes
